# Sim-test coverage of past problem scenarios

An audit (2026-10-18) of every issue and every fix PR in this repository, mapping each real problem scenario to the deterministic simulation test that pins it. Regenerate when a new class of bug lands; a new bug fix must still land with its own seeded sim test (CLAUDE.md, Conventions).

## Method

Candidates: all 273 issues plus the 216 PRs whose title says "fix" (489 items). Each was classified NA (feature, docs, CI, test-harness-only flake, duplicate, unmerged) or a real scenario, and each scenario was matched to a test in the current tree. Status legend:

- **SIM**: a seeded `SimEnv`/`Simulator`/`SimCluster`/`SimWorld` test or corpus cell reproduces the scenario.
- **NEW**: was not sim-covered; this change adds the sim test listed.
- **UNIT**: pinned only by a pure unit/property test or a `ProdEnv`/real-process test, and a sim test would not add much (pure logic, OS/socket/kernel behaviour, operator/UI).
- **NONE**: no regression test, and not sim-expressible (see notes).
- **GAP**: sim-worthy but not covered yet (see notes for why).
- **DELETED**: the subsystem was removed (AP data plane, copy-based split, merge, shared engine, CQL...).

Summary: SIM 203, NEW 27, GAP 2, UNIT 77, NONE 9, DELETED 23; 148 items NA.
