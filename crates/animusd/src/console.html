AnimusDB Data Console

This is the AnimusDB Data Console — a DynamoDB-shaped view of your own tables and items, for application development.

Its screens are not built yet. This placeholder only proves the console has its own listener, separate from the operator dashboard and its admin port.

By design, this console will never show cluster state — no nodes, replicas, tablets, Raft, quorum, leaders, placement, or health. For cluster operation, use the operator dashboard on the node's admin port.
