Compatibility

What your SDK can call, and what it can't.

AnimusDB speaks the DynamoDB wire protocol, so the AWS SDKs and the aws CLI work against it unmodified. Compatibility is not the same as identity, and this page is where the differences are written down rather than discovered.

The data model

A partitioned, sorted map of maps.

A wide-column key/value store in the Dynamo lineage. Tables hold items addressed by a partition key and an optional sort key. Attributes are schemaless: strings, numbers, binaries, booleans, nulls, lists, maps and sets.

If you have modelled for DynamoDB, you have modelled for this. Single-table designs, composite sort keys, sparse indexes and the rest all carry over, because they are properties of the API rather than of the service behind it.

Differences that will show up in your code

Four things to check before you assume a drop-in.

Ordering

Scans are ordered by token

A full Scan returns items in token order, not partition-key order. Sort-key ordering within a partition is preserved. If your code relies on the order a scan happens to produce, it was already relying on something DynamoDB does not promise — but it will now notice.

Capacity

No provisioned or on-demand capacity

There are no RCUs, WCUs or throttling responses to plan around, because there is no billing meter. Your capacity limit is the hardware you gave it, and you find it with monitoring rather than with a quota.

Identity

Credential checks are opt-in

SigV4 verification exists on the client port and is off by default. Until you switch it on, any value works — and everything IAM would enforce, per-table access, condition keys, encryption context, has to be enforced somewhere else.

Ecosystem

The AWS-side integrations aren't there

Streams work, but they aren't Lambda triggers. There are no global tables, no DAX, no CloudWatch. Where a design leans on one of those, that part is a port rather than a config change.

How to test the claim rather than believe it. Point your existing integration suite at a local three-node cluster with --endpoint-url and run it. That takes an afternoon and it is worth more than this table.
