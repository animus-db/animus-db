## How to sign

On a pull request to the Project, post a comment whose entire text is:

```
I have read the AnimusDB CLA and I hereby sign it.
```

The `cla` workflow records your GitHub account name, account id, the date,
the version of this Agreement and a link to the comment in the
`cla-signatures` branch of the repository, which is public. You sign once;
the record covers every later pull request from the same GitHub account.

Sign with the GitHub account that authored your commits. Commits authored by
an e-mail address that is not linked to a GitHub account cannot be matched to
a signature; add the address to your GitHub account, or re-author the
commits.
